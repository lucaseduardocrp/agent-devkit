# Contributing

ADK is open source, but it is not open to contributions. The code is public so anyone can run,
study and self-host it; development is done by the author only.

- **Pull requests are not accepted.** They are closed automatically. If you need a change, fork
  the project under the terms of the [license](LICENSE) and the [trademark policy](TRADEMARKS.md).
- **Skills and plugins go to the ADK Hub.** It has its own repository,
  [agent-devkit-hub](https://github.com/lucaseduardocrp/agent-devkit-hub), which welcomes pull
  requests; its README has the format and the admission rules.
- **Bug reports** are welcome as GitHub issues. Include the version, how you deployed ADK and the
  steps to reproduce.
- **Help with the Railway template** is given in the template's support queue on Railway.
- **Security issues:** do not open a public issue. Report them privately with the "Report a
  vulnerability" button on the repository's Security tab.
