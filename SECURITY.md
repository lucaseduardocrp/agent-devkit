# Security policy

## Reporting a vulnerability

Do not open a public issue or pull request for a security problem. Report it privately with the
**Report a vulnerability** button on the repository's
[Security tab](https://github.com/lucaseduardocrp/agent-devkit/security/advisories/new).

Include what is affected, how to reproduce it and the impact you expect. You will get an answer
within a few days; once a fix is released, the advisory is published with credit to you, unless
you prefer otherwise.

## Supported versions

Fixes go to `main` and to the latest release of `@agent-devkit/cli`. Self-hosted installations
should update to the latest version.
